============================================================
TTL ANALYSIS
============================================================

TTL value decreases by 1 per routing hop:

TTL=128 → Same subnet (no routing)
TTL=127 → 1 hop (MLSwitch routing between VLANs)
TTL=126 → 2 hops
TTL=125 → 3 hops (Branch → Router B → Router A → MLSwitch → HQ)

This confirms traffic is taking the correct path through the network.
